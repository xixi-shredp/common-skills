# Gem5 代码审查

需要审查的 Gem5 代码一般是经过 codex 修改后的代码（可能新增了部分功能，或者修复了部分 bug）

你需要对这份修改后的 gem5 代码仓库进行审查:

- 如果当前 Gem5 仓库是新增了部分功能，请你输出一份详细的架构描述文档
  - 需要描述清楚代码修改了哪些部分，如何实现新增的功能
  - 着重审查对于可能对原有功能造成影响的部分，以及新增功能是否可能存在性能或者正确性的 bug

- 如果当前 Gem5 仓库是修复了部分 bug，请你输出一份详细的审查文档
  - 需要描述清楚代码修改了哪些部分，如何修复了当前 bug
  - 着重审查当前代码的 bug 修复是否可能影响其他部分的性能或者正确性

## Output Rules

输出的所有文档以 markdown 格式来写，主体使用中文，专业术语保留英文 

文档最终写入到用户当前的工作目录下
