# draw.io document and editability reference

The deliverable is an uncompressed `.drawio` XML document whose diagram contents remain directly editable. This note highlights the format constraints relevant to pixel reconstruction; use the linked upstream sources for the full format.

## Minimum structure

The normal hierarchy is:

```text
mxfile (compressed="false")
└── diagram
    └── mxGraphModel
        └── root
            ├── mxCell id="0"
            ├── mxCell id="1" parent="0"
            └── editable vertex and edge cells parented beneath layer 1
```

Use canonical UTF-8 XML and `compressed="false"` so the diagram contains an inspectable `mxGraphModel`. The validator uses `defusedxml`, rejects UTF-16/UTF-32, DTD/ENTITY declarations, compressed/text payloads, wrapper elements, extra hierarchy nodes, active/link content, and non-canonical nested geometry. IDs must be unique. Keep the exact root cell (`0`) and default layer (`1`) forms generated by the converter.

An editable shape is an `mxCell` with `vertex="1"`, `parent="1"`, a style string, and exactly one direct `mxGeometry` containing its `x`, `y`, `width`, and `height`. Keep visible text as an escaped `mxCell` value or a separate text vertex. The generator sets `html=0`; HTML labels are outside the accepted canonical subset.

An editable rotated label remains a normal text vertex. The generator writes `rotation=<degrees>` in its style; draw.io rotates the unrotated `mxGeometry` box around its center. Positive values are clockwise and negative values are counterclockwise. Keep the axis-aligned bounds of the rotated box inside the page so export dimensions remain stable.

An editable connector is an `mxCell` with `edge="1"`, `parent="1"`, `mxGeometry relative="1"`, and either source/target references or explicit source/target points. For attached terminals, the generator converts the scene's endpoint coordinates to exact relative `exitX/exitY` and `entryX/entryY` anchors with `Perimeter=0`; interior points remain ordered waypoints. Use explicit geometry during reconstruction because automatic layout or routing can move cells away from source pixels.

Create a backmost editable rectangle at `x=0`, `y=0`, `width=W`, and `height=H`. Fill it with the intended solid color for an opaque source, or make the boundary transparent for a transparent source. This fixes output bounds without embedding the PNG.

## Image restrictions

Output must contain no image cells, SVG, HTML embeds, data URIs, URLs, external links, or wrapper objects. In particular, do not store the source PNG as a page background, shape image, label payload, SVG wrapper, or hidden/transparent cell. The validator rejects every detected image component; require `stats.image_cells == 0`.

Rebuild special icons with vector shapes or an optional draw.io library stencil. The current implementation has no raster-icon exception path. If vectorization is truly impossible, request user authorization to extend the implementation rather than bypassing validation.

## Rendering and CLI

Use `render_drawio.py` as the stable wrapper for the locally available draw.io Desktop exporter. It parses the single uncompressed page, requires positive integer `pageWidth`/`pageHeight`, passes exact width/height and transparency to draw.io, verifies the PNG mode, and normalizes only the exporter's small bounds-rounding discrepancy. A larger mismatch fails. The completed PNG is atomically moved into place. Compare this raster directly; do not resize either image after rendering to manufacture equal dimensions.

The host draw.io MCP is optional. If available, `search_shapes` can help locate a special library stencil, but direct `mxGraphModel` generation and local rendering must work without it.
