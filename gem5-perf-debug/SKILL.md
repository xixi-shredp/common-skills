# workflow

在增加/修改一个设计，如果造成性能损失，或者性能不符合预期时，进行如下步骤：
1. 检查运行结果的 stats.txt 中的统计变量
2. 如果没有详细的变量和指标，为当前设计增加一定的统计变量之后再运行分析，目的是可以把性能 Bug 具体定位到某个部件的某个指标，以方便后续根据具体的性能指标进行 debug
3. 根据新增的性能指标，定位到具体的问题之后，向用户展示这些问题并解释
4. 如果当下你有合适的解决方案，就向用户展示你的优化方案，并向用户确认是否采用或改进你的优化方案
