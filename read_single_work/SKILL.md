# Read Arch Work

如果需要阅读论文：
以 [PAPER](templates/paper.md) 为模板，生成阅读报告
- 实例可以参考 [IPOP](examples/IPOP.md)

如果需要阅读专利：
以 [PAPENT](templates/patent.md) 为模板，生成阅读报告

要求生成的阅读报告行数不超过 500:  
1. 重点描述文章的核心内容
2. 不要为了凑篇幅就写一些和文章核心不相关的内容
