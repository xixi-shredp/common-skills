# Read Arch Work

## 阅读报告模板

如果需要阅读论文：以 [PAPER](templates/paper.md) 为模板
- 实例可以参考 [IPOP](examples/IPOP.md)

如果需要阅读专利：以 [PAPENT](templates/patent.md) 为模板

## 阅读报告统一要求

- 如果你认为论文的行文思路和模板不匹配，则不需要参考模板，按照论文本身的行文思路生成阅读报告
- 重点描述文章的核心内容
- 不要为了凑篇幅就写一些和文章核心不相关的内容
- 大标题尽量不要使用连续的数字序号，因为我可能会删减报告中的部分章节，这样序号就很难修改
- 报告的术语尽量规范，避免使用口语化的描述
- 主要使用中文，对于专业名词和术语，保留英文
